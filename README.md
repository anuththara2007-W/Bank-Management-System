## 📌 Abstract

This comprehensive banking system is designed to provide **secure, reliable, and user-friendly** banking operations while maintaining the highest standards of **Bank of Code**. Built using C# .NET Framework with modern development practices, this system ensures performance, data security, and quality-driven digital banking.

The system serves different stakeholders:
- 👥 **Customers** - Manage accounts and access all banking services
- 👑 **Administrators** - Manage the entire system and monitor bank operations
- 👔 **Employees** - Process requests and manage banking activities
- 🎫 **Support Team** - Provide customer assistance for smooth operations

### 📥 Installation Steps

```bash
# Step 1: Clone the Repository
git clone https://github.com/anuththara2007-W/Bank-Management-System.git

# Step 2: Navigate to Project Directory
cd Bank-Management-System

# Step 3: Open the Solution
# Double-click the .sln file OR
# Open Visual Studio → File → Open → Project/Solution
```

### 🗄️ Database Configuration

1. **Open SQL Server Management Studio**

2. **Create New Database**
   ```sql
   CREATE DATABASE BankDB;
   ```

3. **Execute Database Scripts**
   - Run the provided SQL scripts in the `/Database` folder
   - Or use the database schema from the project

4. **Update Connection String**
   - Open `App.config` in the project
   - Update the connection string:
   
   ```xml
   <connectionStrings>
     <add name="BankDBConnection" 
          connectionString="Data Source=YOUR_SERVER_NAME;Initial Catalog=BankDB;Integrated Security=True"
          providerName="System.Data.SqlClient" />
   </connectionStrings>
   ```
   
   Replace `YOUR_SERVER_NAME` with your SQL Server instance name

### ⚙️ Build & Run

1. **Restore NuGet Packages**
   - Right-click on Solution → Restore NuGet Packages

2. **Build the Solution**
   - Press `Ctrl+Shift+B` OR
   - Build → Build Solution

3. **Run the Application**
   - Press `F5` OR
   - Debug → Start Debugging

**Purpose:** Set up automated recurring transfers

**Fields:**
- Source Account
- Destination Account
- Amount
- Frequency (Daily/Weekly/Monthly)
- Start Date
- End Date (optional)

**Access:** Customers only
</details>

<details>
<summary><strong>Loan Request</strong></summary>

**Purpose:** Apply for various loan types

**Fields:**
- Loan Type (Personal/Home/Auto/Education)
- Amount Requested
- Purpose
- Employment Details
- Income Information
- Collateral (if applicable)

**Loan Types:**
- Personal Loan
- Home Loan
- Auto Loan
- Education Loan

**Access:** Customers only
</details>

<details>
<summary><strong>My Loans</strong></summary>

**Purpose:** View loan application status and history

**Information:**
- Loan ID
- Loan Type
- Amount
- Status (Pending/Approved/Rejected)
- Application Date
- Approval Date
- Interest Rate
- EMI Amount

**Access:** Customers (own loans only)
</details>

<details>
<summary><strong>Loan Calculator</strong></summary>

**Purpose:** Calculate loan EMI and total cost

**Inputs:**
- Principal Amount
- Interest Rate (%)
- Tenure (months/years)

**Output:**
- Monthly EMI
- Total Amount Payable
- Total Interest
- Amortization Schedule

**Access:** Public (all users)
</details>

<details>
<summary><strong>My Transactions</strong></summary>

**Purpose:** View personal transaction history

**Features:**
- Complete transaction list
- Date range filter
- Transaction type filter
- Search functionality
- Export to PDF/Excel

**Transaction Details:**
- Transaction ID
- Type (Deposit/Withdrawal/Transfer)
- Amount
- Date & Time
- Account Number
- Balance After Transaction

**Access:** Customers (own transactions only)
</details>
